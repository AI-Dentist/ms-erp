# Feature: ai-copilot-mcp
Unify all backend AI into one agent ("Co-Piloto & Monitor de Negocio ERP") plus an MCP server whose tools cover monitoring, CRUD through DDD use cases, generative reports (Text-to-SQL + PDF/Excel) and n8n collection alerts.
Branch: feat/ms-erp-core. Requested contract breaks: `generarReporteInteligente` removed; export route changes to `/api/v1/reports/export/{reporteId}/{format}`.

## Specs
- S1 (TAREA 1, docs): "Modifica ambos archivos de documentación en la raíz del proyecto" (AGENTS.md, SPECS.md). "Cero IA Local en el Backend: Elimina cualquier referencia a IA local en el backend (la IA local corre exclusivamente en el navegador del frontend)."
- S2 (agente): "El **Agente Inteligente (`ErpCopilotAgentUseCase`)** es el único punto de entrada de IA en el backend. Recibe instrucciones en lenguaje natural (provenientes de texto o voz transcrita) o se ejecuta de forma autónoma (\"Monitorea mi negocio\")."
- S3 (MCP tools): "El **Servidor MCP (`ErpMcpToolsService`)** expone 3 categorías de `@Tool` que el Agente invoca según su razonamiento" — a) "**Tools de Monitoreo y Lectura DDD:** Consultan métricas financieras, flujo de caja y pacientes con cuotas vencidas usando los repositorios/casos de uso del dominio." b) "**Tools de Acción y Escritura CRUD (100% vía UseCases DDD):** ... sin tocar SQL directo, pasando siempre por las validaciones del dominio, transacciones `@Transactional` y registro en `audit_logs`": `crearServicioOdontologicoTool`, `registrarEgresoCajaTool`, `reprogramarPlanPagosOAnularDescuentoTool` ("UPDATE sobre cuotas/planes de pago pendientes"), `anularOrdenCobroPendienteTool` ("DELETE lógico cambiando estado a `ANULADO`").
- S4 (reportes): "`generarReporteDinamicoSqlTool`": "Traduce la solicitud a una sentencia SQL de PostgreSQL usando Spring AI." "**Guardrail Anti-SQL Injection (`SqlReadOnlyGuardrail`)** que verifica mediante AST/Regex estricto que la consulta sea únicamente un `SELECT` (prohibido `INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER`, `TRUNCATE`, `;` múltiples o comentarios maliciosos) y la ejecuta dentro de `@Transactional(readOnly = true)`." "Guarda el resultado en caché temporal con un `reporteId` (`UUID`), devuelve las columnas y filas en JSON, sugiere el tipo de gráfico (`BARRAS`, `LINEAS`, `TORTA`, `TABLA`) y genera las URLs listas para descargar el binario en **Excel (`.xlsx` con Apache POI)** y **PDF (con OpenPDF)** en `GET /api/v1/reports/export/{reporteId}/{format}`."
- S5 (n8n): "`dispararAlertaCobranzaN8nTool`: Envía vía webhook a **n8n** recordatorios de cobro por WhatsApp (incluyendo datos de cuota o QR PagoFácil) cuando el Agente detecta morosidad o cuando el administrador se lo ordena."
- S6 (prompt guard): "**Guardrail Anti-Prompt Injection (`PromptInjectionGuardrail`):** Antes de que el Agente procese cualquier instrucción del usuario, valida y bloquea intentos de secuestro de prompt (*jailbreak*, *\"ignora las instrucciones anteriores\"*, intentos de saltar reglas financieras)."
- S7 (TAREA 2): "elimina cualquier controlador, caso de uso o query GraphQL que trate a los reportes generativos de forma separada/duplicada fuera del flujo del Agente/MCP (o intégralo limpiamente como el motor interno de la `@Tool` de reportería del Agente)." "Asegúrate de que no exista ninguna dependencia ni código de frontend en este repositorio."
- S8 (TAREA 3, contrato): add exactly `extend type Query { obtenerEstadoServidorMcp: McpServerStatus!  listarHistorialAgente(limite: Int = 20): [AgenteInteraccionResponse!]! }`, `extend type Mutation { ejecutarAgenteErp(instruccion: String!, modoAutonomoMonitoreo: Boolean = false): AgenteInteraccionResponse! }` and types `McpServerStatus { activo: Boolean! protocolVersion: String! toolsRegistradas: [McpToolMetadata!]! }`, `McpToolMetadata { nombre: String! categoria: String! descripcion: String! }`, `AgenteInteraccionResponse { interaccionId: UUID! fechaEjecucion: DateTime! instruccionOriginal: String! respuestaNaturalAgente: String! toolsMcpInvocadas: [String!]! accionCrudEjecutada: String notificacionN8nEnviada: Boolean! reporteGenerado: ReporteGenerativoPayload }`, `ReporteGenerativoPayload { reporteId: UUID! consultaSqlEjecutada: String! columnas: [String!]! filasJson: String! tipoGraficoSugerido: String! urlDescargaExcel: String! urlDescargaPdf: String! }` — "manteniendo intactas las demás queries y mutations del ERP".
- S9 (TAREA 4): "`ExcelReportExporter.java` (Apache POI) y `PdfReportExporter.java` (OpenPDF) + `ReportExportRestController.java` (`GET /api/v1/reports/export/{reporteId}/{format}`) para que los archivos `.xlsx` y `.pdf` se descarguen reales y bien formateados con membrete de la clínica dental en Bolivianos (Bs)."
- S10 (fallback): "`ErpCopilotAgentUseCase.java` con un modo de respaldo inteligente (*Fallback/Mock Determinístico en perfil `dev`*) en caso de que no haya una API Key de OpenAI/Gemini configurada ... de modo que podamos probar en local tanto el CRUD por agente, como el monitoreo autónomo y la generación de reportes SQL + descarga Excel/PDF sin que falle la aplicación."
- S11: "Al finalizar, ejecuta `./mvnw clean compile` y `./mvnw test` para verificar que todo compile con cero errores."
